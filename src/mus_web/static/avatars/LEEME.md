# Caricaturas de los avatares

Coloca aquí los dibujos, en una carpeta por personaje (el `id` de `avatars/pack.json`):

```
static/avatars/marquesa/frente.png
static/avatars/marquesa/izquierda.png
...
```

Poses (PNG con fondo transparente, 512×512): `frente`, `izquierda`, `derecha`,
`enfrente`, `contento`, `fastidiado` y, opcional, `pillo`. Basta con `frente.png` para
que se use el dibujo; las poses que falten se sustituyen por `frente`. Sin dibujos, la
mesa pinta una cara provisional que también mira a los lados.

Los personajes son caricaturas de parodia con apodos inventados: no uses nombres reales,
logotipos ni nombres de programas.
