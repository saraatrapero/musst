# Imágenes de los naipes (opcional)

La web dibuja la baraja española en SVG (`static/cards.js`). Si prefieres una baraja con
imágenes reales (con licencia que permita usarla), pon aquí un PNG por naipe con su
código: número + inicial del palo (O oros, C copas, E espadas, B bastos).

```
1O.png 2O.png … 7O.png 10O.png 11O.png 12O.png
1C.png … 12B.png
```

Proporción 2:3 (por ejemplo 400×600). Los naipes que falten se siguen dibujando.
